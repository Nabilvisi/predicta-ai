# Paper Atlas fonts

IBM Plex Sans (400, 600) and Instrument Serif (400) are bundled under the SIL Open Font License 1.1. See the two adjacent OFL files. Fonts were downloaded from the official Google Fonts distribution on 2026-10-13 and losslessly packaged as WOFF with fontTools. Family names and glyph data were retained.

Sources:
- https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;600&family=Instrument+Serif&display=swap
- https://github.com/google/fonts/tree/main/ofl/ibmplexsans
- https://github.com/google/fonts/tree/main/ofl/instrumentserif

The application serves WOFF files locally through Streamlit static serving; it makes no runtime request to a font CDN. TTF source files are local preparation artifacts, not required deployment assets.
